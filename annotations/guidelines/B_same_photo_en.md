# Annotation B: is it the same photo? (guideline v1.2, 2026-10-18) — English translation

English translation (2026-10-28) of `B_same_photo_zh.md`, the guideline the two student annotators used. The
Chinese version is authoritative. "Dr Huang" is the author (Eden).

## What you see
Two images side by side, both from companies' sustainability reports. They may come from the same company in
different years, or from different companies.

## What to answer
Are the two **the same photo**, or **the same scene shot from about the same position**?
- **Yes** (press 1)
- **No** (press 2)
- If you hesitate, also tick **Not sure** (press 3). You still have to choose yes or no.

## Before you start
1. Read the example page first: real pairs with the correct answer and a one-line reason.
2. Do 20 practice items. After each answer you see the correct answer and the reason. You need 18 correct to
   start the real items; otherwise read the examples again and do another set of practice items.

## Counts as "yes"
- The same photo, even if cropped, scaled, mirrored, colour-adjusted, blurred by compression, partly covered by
  text or graphics, or placed inside a collage.
- Another shot of the same scene: the same place, about the same angle, the same main content (the same group
  of people or the same things, arranged about the same way). For example two frames of the same group photo
  taken seconds apart; the same building shot from the same position in different years.

## Counts as "no"
- Different scenes.
- The same kind of activity, but different people or a different place.
- The same place, but a clearly different angle.
- The same backdrop or stage, but different people or a different event.

## Quality checks
- Items come in batches of 50 pairs. We check each batch before opening the next.
- Some items have known answers and are used to check quality. If too many are wrong, the batch is redone.

## Rules
- Judge from the two images only; do not search the web.
- Do not discuss items with other annotators.
- About 5 seconds per pair.
- Use a browser on a laptop or desktop, not a phone.
- Ask Dr Huang if anything is unclear.

# 提示詞（PLAN §5 步驟 5）

每個提示詞一個檔，檔名固定。11/2 凍結後不再修改；結果檔的 meta 要記錄每個檔的雜湊。
提示詞只能用開發集的照片調整。

| 檔名 | 給誰 | 用途 |
|---|---|---|
| `gate.txt` | 語言模型 | 讀上下文，輸出 JSON：文字提到的對象（人物、地點、物件、活動、事件）、定錨字串（公司、活動名稱、年份）和 10 字以內的主題。v3（10/19）：只整理、不判斷拍不拍得到（7B 模型判斷時太保守，開發集草稿 20 張有 9–12 張列不出對象），拍不拍得到交給問答那一步 |
| `question.txt` | 語言模型 | 每個對象轉成一個是非題；有前後關係的照 DSG 標出依賴（先問有沒有布條，有才問布條內容） |
| `vqa.txt` | 視覺語言模型 | 問答模板：照片加一個是非題，只回答「是」或「否」 |
| `topical.txt` | 視覺語言模型 | 沒拍到時的主題檢查：「照片內容跟『{主題}』有關嗎？」 |
| `direct_zeroshot.txt` | 視覺語言模型 | 比較對象 E2：照片加上下文，直接三選一（附三級定義） |
| `direct_fewshot.txt` | 視覺語言模型 | 比較對象 E3：E2 加上開發集的 3 個範例（每級一個） |
| `is_photo.txt` | 視覺語言模型 | 照片過濾的檢查：這張圖是不是相機拍的真實照片（`photo_vlm.py`） |
| `section_map.txt` | 語言模型 | 章標題歸類成環境、社會、治理、公司概況、其他 |
